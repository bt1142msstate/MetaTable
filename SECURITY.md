# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in MetaTable, please report it by:

1. **DO NOT** open a public issue
2. Email the details to: bt1142@msstate.edu
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

You can expect:
- Initial response within 48 hours
- Regular updates on the status
- Credit for responsible disclosure (if desired)

## Security Best Practices

When using MetaTable:
- Only scan directories you trust
- Be cautious with network drives and shared folders
- Review Excel output before sharing (may contain sensitive file paths)
- Keep your .NET runtime updated

Thank you for helping keep MetaTable secure!
